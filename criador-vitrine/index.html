Senhas Protegidas (SHA-256)

As senhas são armazenadas como hash criptográfico SHA-256. Isso significa que mesmo que alguém acesse o arquivo de usuários, não conseguirá ver as senhas reais.

Formato da Planilha Excel

A planilha deve conter as seguintes colunas:

usuario - Login
senha_hash - Hash SHA-256
nome - Nome completo
nivel - admin ou usuario

Use o Gerador de Hash abaixo para criar o hash da senha e colar na coluna senha_hash.

Gerador de Hash SHA-256

Digite a senha desejada e copie o hash gerado para colocar na planilha Excel (coluna senha_hash).
